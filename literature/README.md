# literature/

- `search/protocol.md`: streams, seed works, databases, inclusion criteria.
- `search/search-strings.md`: exact strings per database, with run dates.
- `search/exports/`: raw RIS/BibTeX/CSV exports from manual database runs.
- `search/screening.csv`, `search/search-log.md`: produced by `/lit-search`.
- `fulltext/`: PDFs of included papers, named `<citationkey>.pdf`. Not
  committed if licence terms forbid it (add a `.gitignore` line).
- `synthesis/`: concept matrix, stream memos, gap statement, theory
  outline, qualitative measurement memo and propositions.
- `references.bib`: verified bibliography (Better BibTeX export).
- `zotero/`: RIS files for manual import when the API is unavailable.
