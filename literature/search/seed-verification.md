# Seed verification

Run date: 2026-10-02. Agent: literature-searcher (Stage 1).
Scope: the 28 seed works named in `protocol.md`. Nothing here is added to `literature/references.bib`; the reference-manager verifies each entry against Crossref before any citation is used.

Method and limits. Each seed was checked with WebSearch (one query per seed, built from the protocol's author-year-outlet string) and, where WebSearch returned only indirect evidence, with a Consensus query. Crossref (api.crossref.org), OpenAlex (api.openalex.org) and Wiley article pages were blocked by the session's egress policy (HTTP 403 / EGRESS_BLOCKED) and were not retried or routed around. A "DOI" below is therefore only what a search result showed (a publisher URL or a search summary) and is not Crossref-verified. Details I put into my own queries (volume, issue, title wording) are not counted as evidence; only what the source returned is recorded. Two of my own query titles were wrong (Gong 2003, Li et al. 2018); the sources corrected them.

Status vocabulary: confirmed (authors, year, outlet each backed by a returned source), corrected (the protocol's outlet or authors differ from the source), unconfirmed (no source found). No seed is unconfirmed; four carry caveats listed under "Flags".

Any Consensus record carrying that outlet is probably a Strategic Management Journal paper; the screening sheet records the verified outlet where a source confirmed it and keeps the Consensus value otherwise.
