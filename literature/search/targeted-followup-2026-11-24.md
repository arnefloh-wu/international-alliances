# Targeted follow-up search, 2026-11-24

Stage 1 increment (literature-searcher), run on 2026-11-24 for the gate 2
re-run. It covers the search requests in
`literature/synthesis/missing-references.md`, meaning the claims for which no
work is named yet. Queries, counts and the PRISMA flow are in
`literature/search/search-log.md` (section "2026-11-24 targeted follow-up").
Proposed strings for the manual runs are in `literature/search/search-strings.md`,
section of the same name. Every record below is a row in
`literature/search/screening.csv` with the id shown.

Status of every record: screened on title and abstract only. Nothing has
been verified. DOIs are given exactly as OpenAlex returned them. No record has
been added to `literature/references.bib` or Zotero, and none may be cited
until the reference-manager has verified it. This memo is a list of candidates
and contains no synthesis. Where it says "nothing relevant found", that holds
only for the 24 OpenAlex and 2 WebSearch queries run here, with the first page
screened per query. It is not a claim about the literature. The Consensus
connector was not available in this session (no Consensus tool was exposed,
although the PI asked for it), and Web of Science, EBSCO and Google Scholar
have not been run.

Decision codes: `include` and `unsure` go to full text. A reason that starts
with `scope:` marks a record outside protocol criteria (a) to (g) that is kept
only because it is the sole evidence found for a request; the PI decides at
gate 2 whether to amend the protocol.
