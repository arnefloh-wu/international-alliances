# reviews/

Gate files and internal review reports.

- `gate-<n>-<slug>.md`: one per stage, created from `GATE-TEMPLATE.md` by
  the stage agent. The PI sets `Status:` to APPROVED, APPROVED WITH
  CHANGES or REJECTED and adds notes. Agents never change the status
  except to record a chat approval with the date.
- `shock-options.md`: produced by `/research-workflow hypotheses` when the
  focal shock is still open.
- `review-<date>-<scope>.md`: internal review reports.

Gate list: 1 literature search, 2 synthesis, 3 qualitative phase,
4 pilot, 5 pre-analysis plan, 6 panel, 7 results, 8 sections (one file
each), 9 full draft, 10 submission readiness.
